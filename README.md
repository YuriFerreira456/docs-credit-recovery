## 🚀 Início Rápido

### 1. Identifique o Tipo de Issue

| Situação | Template |
|----------|----------|
| Erro ou comportamento inesperado | [Bug Report](templates/BUG_REPORT.md) |
| Dúvida ou pedido de ajuda | [Support Request](templates/SUPPORT_REQUEST.md) |
| Problema crítico em produção | [Incident Report](templates/INCIDENT_REPORT.md) |
| Nova funcionalidade ou melhoria | [Feature Request](templates/FEATURE_REQUEST.md) |

### 2. Use o Template

1. Acesse o template correspondente
2. Copie o conteúdo
3. Preencha todas as seções relevantes
4. Submeta sua issue

### 3. Acompanhe

Monitore o status da sua issue e responda prontamente quando houver solicitações de informação adicional.

## 📊 Níveis de Prioridade

| Prioridade | Resposta | Resolução | Critério |
|------------|----------|-----------|----------|
| 🔴 P1 Crítica | < 1h | < 4h | Sistema indisponível |
| 🟠 P2 Alta | < 4h | < 24h | Funcionalidade principal afetada |
| 🟡 P3 Média | < 8h | < 72h | Funcionalidade secundária |
| 🟢 P4 Baixa | < 24h | < 1 semana | Problema menor |
