# 📁 Templates de Support Issues

Esta pasta contém templates prontos para uso na criação de diferentes tipos de support issues.

## Templates Disponíveis

| Arquivo | Descrição | Quando Usar |
|---------|-----------|-------------|
| [BUG_REPORT.md](./BUG_REPORT.md) | Relatório de Bug | Quando encontrar erro ou comportamento inesperado |
| [SUPPORT_REQUEST.md](./SUPPORT_REQUEST.md) | Solicitação de Suporte | Para dúvidas, pedidos de ajuda ou configuração |
| [INCIDENT_REPORT.md](./INCIDENT_REPORT.md) | Relatório de Incidente | Para documentar incidentes de produção |
| [FEATURE_REQUEST.md](./FEATURE_REQUEST.md) | Solicitação de Funcionalidade | Para sugerir novas features ou melhorias |

## Como Usar

1. **Escolha o template** adequado para sua necessidade
2. **Copie o conteúdo** do template
3. **Preencha todas as seções** aplicáveis
4. **Remova seções** não utilizadas (opcional)
5. **Submeta a issue** no sistema de tickets

## Dicas

- ✅ Seja claro e objetivo nos títulos
- ✅ Forneça o máximo de detalhes possível
- ✅ Anexe evidências (screenshots, logs)
- ✅ Verifique se já existe issue similar
- ❌ Não deixe campos obrigatórios em branco
- ❌ Não inclua informações sensíveis

## Estrutura dos Templates

Todos os templates seguem uma estrutura consistente:

```
1. Informações Básicas
2. Classificação/Tipo
3. Descrição Detalhada
4. Evidências/Anexos
5. Impacto/Prioridade
6. Checklist de Submissão
```
